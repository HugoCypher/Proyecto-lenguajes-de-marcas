Temario

Unidades del tema de lenguajes de marcas y XML.

Unidad 1

Conceptos generales

Los lenguajes de marcas sirven para estructurar información. No programan, solo etiquetan datos.

XML permite crear tus propias etiquetas. Se usa para intercambiar datos entre programas.

Ejemplo:

<persona> <nombre>Laura</nombre> <edad>22</edad> </persona>

Árbol: persona → nombre, edad

¿Para qué sirve XML?
Unidad 2

Estructura y sintaxis

Un XML suele empezar con la declaración:

<?xml version="1.0" encoding="UTF-8"?>

Los elementos tienen etiqueta de apertura y de cierre. Los atributos van entre comillas:

<libro id="1" idioma="es"> <titulo>Aprendiendo XML</titulo> </libro>

Unidad 3

Documentos bien formados

Para que un XML esté bien formado tiene que cumplir:

  • Una sola raíz
  • Etiquetas abiertas y cerradas
  • Nombres iguales (también mayúsculas)
  • Anidación correcta
  • Atributos entre comillas

Correcto:

<biblioteca> <libro> <titulo>XML básico</titulo> </libro> </biblioteca>

Incorrecto (mala anidación):

<biblioteca> <libro> <titulo>XML básico </libro> </titulo> </biblioteca>
¿Cuántas raíces puede haber?
Unidad 4

Bien formado vs validado

Bien formado = cumple las reglas de sintaxis (etiquetas, anidación, etc.).

Válido = además sigue un DTD o XSD (estructura concreta).

Si no está bien formado, no puede ser válido.

Unidad 5

Namespaces

Los namespaces evitan que dos etiquetas con el mismo nombre se confundan cuando se mezclan vocabularios distintos.

<root xmlns:lib="http://ejemplo.com/libros"> <lib:libro> <lib:titulo>XML práctico</lib:titulo> </lib:libro> </root>
